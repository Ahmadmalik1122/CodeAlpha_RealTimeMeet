## ⚡ Features

- 📹 **HD Video & High-Quality Audio**: Low-latency peer-to-peer media streaming via WebRTC.
- 💬 **Live In-Call Chat**: Instant messaging during active call sessions powered by Socket.io signaling.
- 🎙️ **Media Controls**: Dynamic microphone mute/unmute, video toggle, and device switching.
- 🖥️ **Screen Sharing**: One-click screen and application window presentation.
- 🔒 **Secure Peer Connections**: Encrypted media channels utilizing SRTP / DTLS protocols.
- 📱 **Responsive UI**: Sleek, glassmorphic layout tailored for both Desktop and Mobile views.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), WebRTC API
- **Backend**: Node.js, Express.js
- **Signaling**: Socket.io / WebSockets
- **Protocols**: ICE, STUN / TURN servers
